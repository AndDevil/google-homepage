# 🌐 Responsive Google Homepage Clone

A simple and responsive clone of the **Google homepage** built using **HTML and CSS**.  
This project was created as a practice exercise to strengthen front-end development skills and understand the structure and styling of modern web layouts.

---

## ✨ Goals of the Project
- Practice **HTML & CSS fundamentals**.  
- Recreate the familiar Google homepage layout with a **search bar and logo**.  
- Ensure **responsive design** for desktop and mobile devices.  
- Build a project that mimics a real-world, widely recognized UI.  

---

## 🛠️ Tech Stack
- **HTML5** – Semantic page structure  
- **CSS3** – Styling, alignment, responsiveness  

---

## 🚀 Features
- 📱 **Responsive Design** – Works across desktop, tablet, and mobile.  
- 🔎 **Search Bar Layout** – Styled similar to Google’s search input field.  
- 🎨 **Google Logo & Layout** – Mimics the clean, minimal design of Google’s homepage.  
- 🌍 **Cross-Browser Compatibility** – Works on all modern browsers.
